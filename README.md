# Camino Dorado — Technical Contact

This repository provides a public technical contact point for Camino Dorado, an independent project focused on organizing and verifying publicly available sports facts and results.

## Automated access inquiries

For questions about automated data access, API usage, identification, or operational issues related to Camino Dorado, please open a GitHub Issue in this repository.

Contact:
https://github.com/jpmoreno8/camino-dorado-contact/issues

This repository does not contain the Camino Dorado application, its source code, athlete data, or internal project documentation.

## Data access principles

Camino Dorado aims to respect applicable API policies, access restrictions, attribution requirements, and third-party rights.

The availability of information on a public website is not treated as automatic permission for unrestricted extraction, storage, or republication.
